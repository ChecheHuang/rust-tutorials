# 故事版：遊樂園的分流閘門 🎡

> 這篇是**寫給小朋友也看得懂**的故事版。用一個「週末去遊樂園玩」的故事，幫你「感覺」出 `if` 是 expression、`loop` 帶值 `break`、`while`、`for` 與 range、`match` 的窮盡與 guard、`@` binding、`if let`、`while let`、`let else` 和 labeled `break` 是什麼。故事裡不講程式名詞，名詞都放在 `>` 小框框和最後的對照表裡。先享受故事，別急著背。

---

## 問一句就拿到答案

小樂和姊姊到了遊樂園門口。小樂問售票姊姊：「我 5 歲，要買哪一種票？」

售票姊姊不是說「嗯……你等一下，我先去記在一張紙上，再……」，而是**直接回答**：「單數歲的小朋友，這個月拿**藍色票**！」

小樂把答案握在手上，就是一張藍色票。

> 這就是 **`if` 是 expression**：`let parity = if n % 2 == 0 { "even" } else { "odd" };`。`if` 本身就會「回答一個值」，可以直接放進變數。所以 Rust **不需要** `? :` 三元運算子。

---

## 一直轉，直到轉到為止

入口有一台**轉蛋機**。規則是：一直轉，轉出來的號碼「自己乘自己」超過 100，就可以**拿著那個號碼**進場。

小樂轉 1、2、3……轉到 11 的時候，11 × 11 = 121，超過了！他**停下來，帶著 11 走**。

> 這就是 **`loop` + `break` 帶值**：`let answer = loop { i += 1; if i * i > 100 { break i; } };`。`loop` 是無條件一直轉，`break i` 是「停下來，順便把 i 帶出去」。

---

## 氣球打氣站

小樂拿到一顆癟癟的氣球。打氣站阿姨說：「**只要還不夠大**，我就再打一下。」

噗、噗、噗……氣球一直變大，等到夠大了，阿姨就停手。

> 這就是 **`while`**：`while s.len() < 10 { s.push('!'); }`。每一輪先看條件，條件不成立就停。

---

## 排隊搭小火車

小火車有三節車廂，車廂上寫著「**1 號到 3 號（3 號也算）**」。小樂一節一節走過去，每節都揮揮手。

另一邊的旋轉木馬寫著「1 號到 3 號（**不含** 3 號）」，所以只有 1、2 兩匹馬可以騎。

> 這就是 **`for` 與 range**：`for x in 1..=3` 是 1、2、3；`1..3` 只有 1、2。也可以邊走邊數號碼：`for (i, c) in "abc".chars().enumerate()`。Rust **沒有** C 那種 `for(i=0;i<n;i++)`。

---

## 一定有出口的分流閘門

園區中央有一座**分流閘門**。你說你要去哪個方向，閘門就給你一張方向卡：

- 「北」→ 往上走一格
- 「南」→ 往下走一格
- 「東」、「西」→ 往右、往左
- **其他任何答案** → 原地不動

設計閘門的工程師說：「我們的規定是：**每一種可能的人都一定要有出口**。如果有一種人沒地方去，這座閘門**根本不准蓋**。」

而且每個人只會走進**一個**出口，不會走一走跑進隔壁出口。

> 這就是 **`match` 必須窮盡**：`match dir { "north" => (0, 1), ..., _ => (0, 0) }`。漏掉可能性編譯就失敗；`_` 是「其他所有人」的出口。也沒有 `switch` 的 fallthrough。

### 加一道附加條件

雲霄飛車的閘門更講究：

- 有票、**而且**身高超過 5 格 → 「大雲霄飛車」
- 有票（但不夠高）→ 「小雲霄飛車」
- 沒票 → 「回去買票」

閘門先看「有沒有票」，再看「夠不夠高」這道**附加條件**。

> 這就是 **match guard**：`Some(n) if n > 5 => format!("big {n}")`。注意 guard 不算「已經涵蓋全部」，所以後面還要有 `Some(n) =>` 接住沒通過的人。

### 看座標分區

園區地圖用兩個數字表示位置。閘門看你的座標說：「(0, 0) 是**正中央**噴水池；右邊那條線上是**東大道**；右上方那一區是**第一園區**……都不是的話，就是『其他地方』。」

> 這就是 **tuple destructure + range pattern**：`match point { (0, 0) => "origin", (x, 0) if x > 0 => "positive x-axis", (1..=10, 1..=10) => "small Q1", _ => "elsewhere" }`。一個 arm 可以一次對兩個數字、甚至一整段範圍。

---

## 分組時順便記下身高

量身高的叔叔不只告訴你「你是中班」，還會**在手環上寫下你的真實身高**。

「1 到 5 是小班，6 到 10 是中班。你是 7——**中班，身高 7**！」

> 這就是 **`@` binding**：`x @ 6..=10 => println!("medium ({x})")`。同時知道「屬於哪個範圍」**和**「確切是多少」。

---

## 只在乎一件事

姊姊說：「我只在乎**有沒有抽到獎**。有就拿出來給我看；沒有就算了，不用跟我報告。」

> 這就是 **`if let`**：`if let Some(x) = some_val { println!("got {x}"); }`。只處理一種情況的 `match` 簡寫。但它**不會**強迫你處理另一種情況，要記得自己想想 `else`。

### 一直拿到拿完

紀念品店櫃台上疊著三個盒子。店員說：「**只要上面還有盒子**，就拿最上面那個給下一位。」3、2、1——疊子空了，就停。

> 這就是 **`while let`**：`while let Some(top) = stack.pop() { ... }`。`pop()` 拿到 `Some` 就繼續，拿到 `None` 就停，是處理 stack / queue 的標準寫法。

---

## 沒有手環就請回

鬼屋入口的工作人員規定：「**先檢查手環**。有手環，就拿著它進去；沒手環，**直接請回**，不准往裡面走。」

這樣進到鬼屋裡的每一個人，都**一定有手環**，裡面的工作人員不用再一個一個問。

> 這就是 **`let else`**：`let Some(parsed) = "42".parse::<i32>().ok() else { return; };`。對不上就**一定要離開**（`return`、`break`、`panic!`），對上了，後面的程式就能直接用 `parsed`，不必一層一層巢狀。

---

## 迷宮裡大喊一聲

最後一站是**三層迷宮**。規則是：在裡面找到「兩個數字相乘等於 42」的牌子。

小樂在第二層、第三層之間繞來繞去，終於找到「6 × 7」！他不用一層一層慢慢往回走，而是對著喇叭大喊**迷宮的名字**：「**外層迷宮，我找到了！**」——整個人直接被送到出口，手上還拿著那塊牌子。

> 這就是 **labeled break**：`let pair = 'outer: loop { for x in 1..10 { for y in 1..10 { if x * y == 42 { break 'outer (x, y); } } } ... };`。label 用單引號開頭，可以從多層迴圈直接跳出來，還能帶值。

## 回到現實：故事 ↔ Rust 對照表

| 故事裡的東西 | 真正的 Rust 概念 |
|------|------|
| 售票姊姊直接回答票種 | **`if` 是 expression** |
| 轉蛋轉到才帶號碼走 | **`loop` + `break i`** |
| 不夠大就再打氣 | **`while`** |
| 1 到 3 號（含 3）的小火車 | **`1..=3`** |
| 不含 3 號的旋轉木馬 | **`1..3`** |
| 每種人都有出口的閘門 | **`match` 窮盡** |
| 「其他任何答案」的出口 | **`_`** wildcard |
| 走進一個出口不會跑到隔壁 | **沒有 fallthrough** |
| 有票還要夠高 | **match guard** `if n > 5` |
| 看座標分區 | **tuple / range pattern** |
| 分組順便寫下身高 | **`@` binding** |
| 只在乎有沒有抽到獎 | **`if let`** |
| 一直拿最上面的盒子 | **`while let` + `pop()`** |
| 沒手環就請回 | **`let else`** |
| 對迷宮名字大喊 | **labeled `break 'outer`** |

---

## 一句話記住

> **在 Rust 的遊樂園裡，每個閘門問一句就給答案（`if` / `match` 都是 expression），而且每一種人都一定要有出口（`match` 窮盡）；只在乎一種就用 `if let`，沒資格就在門口請回（`let else`）。**
