# 故事版：三年二班的名牌與收納格 🏷️

> 這篇是**寫給小朋友也看得懂**的故事版。用一個「開學第一天整理教室」的故事，幫你「感覺」出 `let` 與 `mut`、shadowing、各種大小的型別、`char`、`bool`、型別推導與 turbofish、整數溢位的四種處理、`as` 與 `TryFrom`、`const` 和 `()` 是什麼。故事裡不講程式名詞，名詞都放在 `>` 小框框和最後的對照表裡。先享受故事，別急著背。

---

## 原子筆名牌

開學第一天，王老師發給每個人一張名牌，說：「名字請用**原子筆**寫。」

小美寫下「5」號座位。寫完才想改成 6 號——可是原子筆**擦不掉**。

老師笑著說：「這就是要大家想清楚再寫。看到原子筆名牌，大家就知道**它不會變**。」

> 這就是 **`let` 預設不可變**：`let x = 5;` 之後寫 `x = 6;` 會編譯失敗（cannot assign twice）。看到 `let x` 就知道 x 不會再被改。

### 鉛筆寫的值日生表

但是「今天的值日生」每天都會換。老師在白板角落用**鉛筆**寫上「5 號」，旁邊還放了一塊橡皮擦，隔天擦掉改成「6 號」。

> 這就是 **`let mut`**：`let mut y = 5; y = 6;` 可以改。**要改就要明講**，Rust 不會偷偷讓東西變來變去。

---

## 貼一張新名牌蓋上去

小強的名牌上寫著文字「**五**」，老師想要大家都用數字。

老師沒有去擦原子筆，而是拿一張**新名牌**，寫上數字「5」，直接**蓋在舊名牌上面**。後來又再蓋一張「10」（因為他報名了兩個社團，號碼要乘以 2）。

大家看到的永遠是**最上面那張**。而且新名牌可以寫跟舊的完全**不同種類**的東西——舊的是文字，新的是數字。

> 這就是 **shadowing**：`let z = "5"; let z: i32 = z.parse().unwrap(); let z = z * 2;`。每個 `let z` 都是**新的變數**蓋掉舊的，不是修改，所以**型別可以不一樣**。`mut` 只能改值，不能換型別。

---

## 大小不一樣的收納格

教室後面有一整面收納櫃，格子**大小都不一樣**：

- 小小格只能放 -128 到 127 張貼紙
- 大格子能放到 40 億張，但**不能放負的**（只收不借）
- 還有專門放「有小數點的東西」的格子，像 3.14 公分的鉛筆

老師說：「每樣東西都要放進**剛好的格子**。不能把小數點的鉛筆，硬跟整數的貼紙混在同一格算。」

> 這就是 **基本型別**：`i8`（-128..127）、`u32`（無號，可到 40 億）、`f64`（浮點，預設）。整數字面值預設是 `i32`。不同型別**不能直接混著算**，`i32 + f64` 會編譯失敗，要先轉型。陣列索引一定要用 `usize`。

### 一個字一格

有一種格子專門放「**一個字**」。英文字母 A 可以放，中文字「**我**」也可以放——因為這格子做得夠大（4 個單位寬）。

> 這就是 **`char`**：4 bytes，一個 Unicode scalar，所以 `let e: char = '我';` 合法。它**不是** byte（byte 是 `u8`）。

### 只有開跟關的電燈開關

教室電燈開關只有「**開**」和「**關**」。有同學說：「我把它撥到 0！」老師搖頭：「開關上沒有 0，只有開和關。」

> 這就是 **`bool`**：只有 `true` / `false`。Rust 的 `if` 條件**必須是 bool**，`if 0` 會編譯失敗，要寫 `if n != 0`。

## 老師一看就知道

小美把三顆彈珠放進一個盒子交給老師。老師沒問，就在盒子上貼了「**整數彈珠盒**」的標籤——一看就知道。

可是小強交來一張紙條寫著「42」，老師就問了：「這是要當**數字**，還是要當**文字**？要多大的格子？」小強在紙條上補寫：「請當**大號整數**。」

> 這就是 **型別推導與 turbofish**：`let v = vec![1, 2, 3];` 編譯器推得出是 `Vec<i32>`。推不出來時要標註：`let v2: Vec<u8> = ...`，或用 turbofish 告訴函式要轉成什麼：`"42".parse::<i64>()`。

---

## 數到 255 就滿的計數器

班上有一個點名用的**轉盤計數器**，最多只到 255。今天已經轉到 255 了，又來了一位同學。

老師說：「這時候有四種處理方法，你們要**自己先選好**：」

1. **繞回去**：轉盤轉一圈回到 0。
2. **先問一下**：「加得下嗎？」加不下就回答「**沒辦法**」。
3. **卡在最大**：停在 255，不再往上。
4. **繞回去，但舉紅旗**：轉回 0，同時舉起一面「剛剛爆掉了！」的旗子。

「如果你什麼都沒選，」老師說，「**練習的時候**計數器會大叫停下來，提醒你出事了；**正式比賽時**它就默默繞回 0。這樣太危險，所以要自己選。」

> 這就是 **整數溢位**：`u8::MAX` 是 255。`wrapping_add(1)` → 0；`checked_add(1)` → `None`；`saturating_add(1)` → 255；`overflowing_add(1)` → `(0, true)`。不指定的話：debug build **panic**，release build **wrap around**。

---

## 硬塞 vs 先試試看

小強想把 **300** 張貼紙塞進最多只能裝 255 的小格子。

他**硬塞**進去：格子沒有抱怨，可是多出來的部分像轉盤一樣繞了一圈，最後格子上顯示 **44**。小強嚇一跳：「我的貼紙呢？」

小美比較聰明。她先問格子：「**你裝得下 300 嗎？**」格子回答：「**裝不下喔**。」小美就知道要換大格子。

> 這就是 **`as` vs `TryFrom`**：`300_i32 as u8` 會**截斷**成 44，而且**永遠不 panic、不告訴你**。安全的做法是 `u8::try_from(big)`，裝不下會回 `Err(TryFromIntError)`。對外部輸入一律用 `TryFrom`。

---

## 牆上的班規

教室前面牆上貼著一張**班規**：「**全班最多 1,000 人**。」

這張是學期開始前就印好的，大家都看得到，**誰都不能改**，也不能拿新的蓋上去。

> 這就是 **`const`**：`const MAX_USERS: u32 = 1_000;`，必須標型別、必須是編譯期就算得出來的值、命名用大寫蛇形、不能 shadowing。`1_000` 裡的底線只是方便閱讀。

---

## 只寫「收到」的回條

老師發了一張回條：「請家長簽名交回。」回條上**沒有要填任何答案**，只要交回來，老師就知道「收到了」。

> 這就是 **unit type `()`**：只有一個值 `()`，代表「**沒有有意義的回傳值**」。Rust 沒有 `void`，函式不寫回傳型別就是回傳 `()`。

## 回到現實：故事 ↔ Rust 對照表

| 故事裡的東西 | 真正的 Rust 概念 |
|------|------|
| 原子筆名牌（擦不掉） | **`let`**（預設不可變） |
| 鉛筆值日生表 | **`let mut`** |
| 新名牌蓋在舊名牌上 | **shadowing** |
| 蓋上去的可以換成數字 | shadowing **可以換型別** |
| 大小不同的收納格 | **`i8` / `u32` / `f64`** 等型別 |
| 只收不借的格子 | **無號整數** `u*` |
| 一個字一格（中文也行） | **`char`**（4 bytes） |
| 只有開和關的開關 | **`bool`** |
| 老師一看就知道 | **型別推導** |
| 紙條上補寫「請當大號整數」 | **turbofish** `parse::<i64>()` |
| 到 255 就滿的轉盤 | `u8::MAX` |
| 繞回去 / 先問 / 卡住 / 舉紅旗 | `wrapping_` / `checked_` / `saturating_` / `overflowing_add` |
| 練習時大叫、比賽時默默繞回 | debug **panic** / release **wrap** |
| 硬塞 300 變 44 | **`as`** 截斷 |
| 先問「裝得下嗎」 | **`u8::try_from`** 回 `Result` |
| 牆上的班規 | **`const`** |
| 只寫「收到」的回條 | **`()`** unit type |

---

## 一句話記住

> **名牌預設用原子筆寫（`let`），要改就明講用鉛筆（`mut`），想換內容就蓋一張新的（shadowing）；每樣東西放進剛好大小的格子，塞不下時要自己選怎麼辦，別用 `as` 硬塞，先問一句 `try_from`。**
