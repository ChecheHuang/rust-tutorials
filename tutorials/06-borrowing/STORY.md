# 故事版：美術社的那塊白板 🖍️

> 這篇是**寫給小朋友也看得懂**的故事版。用一個「美術社大家共用一塊白板」的故事，幫你「感覺」出借用、`&T` 共享借用、`&mut T` 獨佔借用、「多讀 XOR 一寫」規則、NLL、借給函式、reborrow、不能 dangling 和 auto deref 是什麼。故事裡不講程式名詞，名詞都放在 `>` 小框框和最後的對照表裡。先享受故事，別急著背。

---

## 只是想看一下

美術社教室前面有一塊**大白板**，是社長小芸的。上面寫著這週要畫的主題：「hello」。

社員阿凱想知道主題有幾個字。他當然**不用把整塊白板搬回家**——走過去**看一眼**就好了，看完白板還是小芸的。

> 這就是 **借用（borrow）**：上一章學到交出去（move）之後原主人就不能用了，可是很多時候我們只想「**暫時用一下，不拿走**」。Rust 用 `&` 表示借用。

---

## 大家一起看

下課時間，阿凱、小米、阿豪**三個人同時**站在白板前面看主題。

沒有人會說「你先讓開，我要看」——**看**這件事，多少人一起都沒問題。而且只是看的人，手上都**沒有白板筆**，誰也不能改上面的字。

> 這就是 **`&T` 共享借用**：`let r1 = &s; let r2 = &s;` 可以同時有很多個，但都**不能修改**。借出去的同時，小芸（owner）自己也還是可以看：`println!("owner still valid: {s}")`。

---

## 只有一支白板筆

白板筆**只有一支**。誰拿到筆，誰才能在白板上寫字。

小芸把筆交給阿豪：「你把主題改成『hi, world』。」阿豪寫的時候，小芸規定：「**他在寫的時候，其他人都先不要看**，不然你們會看到寫一半的字，每個人抄回去的都不一樣。」

連小芸自己，在阿豪寫完之前，也**先不碰**白板。

> 這就是 **`&mut T` 獨佔借用**：`let m = &mut s2; m.push_str(", world");`。同一時刻**只能有一個** `&mut`，而且它存在的期間，**任何其他** `&` 或 `&mut` 都不能用，連 owner 本身也不行。

### 這塊白板本來就要能擦寫

隔壁合唱團的是**玻璃框公告欄**，鎖起來的，誰都寫不了。只有美術社這種**一開始就說好「可以擦寫」**的白板，才能把筆借出去改字。

> 這就是 **owner 必須是 `mut`**：要 `&mut s2`，前面一定是 `let mut s2 = ...`。

---

## 社團的鐵律：要嘛很多人看，要嘛一個人寫

小芸在白板角落寫了一條社規：

> **同一時間，要嘛很多人在「看」，要嘛只有一個人在「寫」，絕對不能一邊有人看、一邊有人寫。**

這樣大家抄下來的主題，永遠都是**完整、一致**的。

> 這就是 **借用規則「多讀 XOR 一寫」**：任意多個 `&T`，**或**恰好一個 `&mut T`，不能同時存在。這是 Rust 在**編譯期**防止 data race 的根基。

---

## 看完就走，不用等下課鐘

以前的社規比較死板：「只要你**今天**看過白板，就算你在**這節課**結束前都算『正在看』。」結果阿凱看一眼就去畫畫了，阿豪卻要等到下課鐘響才能拿筆寫字。

後來小芸改了規定：「你**最後一次看完**，就算你離開了。」阿凱和小米看完最後一眼回座位，阿豪**馬上**就能拿筆。

> 這就是 **NLL（Non-Lexical Lifetimes）**：借用活到「**最後一次使用**」，不是活到 `}`。程式裡 `a`、`b` 印完之後不再使用，接下來 `let c = &mut v; c.push(4);` 就可以通過。

---

## 借給別社的人

**算字數**：攝影社的學長來問：「你們主題幾個字？」小芸讓他**站在白板前看**，學長數完就走，白板還在美術社。

**幫忙加字**：書法社的學姊字很漂亮，小芸把**白板筆借她**：「幫我在後面加上『hello』。」學姊寫完，把筆**還回來**，白板上多了字，而且白板還是美術社的。

> 這就是 **借給函式**：`calc_len(&s3)` 只讀，呼叫完 `s3` 照樣能用；`append_hello(&mut s4)` 借出寫的權利，函式裡 `s.push_str(" hello")`，回來後 `s4` 就變了。函式參數**優先用借用**，除非函式真的要「拿走」。

---

## 拿筆的人把筆轉借給助手

阿豪拿著白板筆正要寫，旁邊的學弟說：「我想加一個驚嘆號！」

阿豪把筆**暫時**遞給學弟：「你寫，寫完**還我**。」學弟在後面加了「!」，把筆還給阿豪。在學弟拿筆的那段時間，阿豪自己**也不能寫**；學弟一還，阿豪又可以繼續了。

> 這就是 **reborrow**：`let inner: &mut String = &mut *outer;`。`outer` 暫時把獨佔權借給 `inner`，inner 的 block 結束後，`outer` 重新生效（`println!("via outer: {outer}")`）。把 `&mut` 變數傳給函式時，編譯器常常**自動**幫你這樣做。

---

## 不能給一張指向「待拆白板」的紙條

阿凱放學前想把自己在**隔壁空教室**白板上畫的草稿留給小米。可是那間空教室**今天放學就要拆掉**。

如果他只給小米一張紙條：「去隔壁教室看我的白板喔」，明天小米去看，教室早就不見了，紙條**指向一個不存在的地方**。

小芸說：「這種紙條**我不准你寫**。要嘛你把草稿畫在一塊**小白板**上，整塊送給小米帶走。」

> 這就是 **不能有 dangling reference**：`fn dangle() -> &String` 回傳函式內局部變數的參考會編譯失敗，因為函式結束時它就被 drop 了。正確做法是回傳**擁有的資料**：`fn give_owned() -> String`。

---

## 看白板不用說「走到白板前」

新社員每次都說：「我要**走到白板前面**，然後**看上面的字**，然後把它唸成小寫。」

小芸笑說：「你直接說『**把白板的字唸成小寫**』就好啦，大家知道要先走過去。」

> 這就是 **auto deref**：對 `&String` 呼叫方法，不用寫 `(*s_ref).to_lowercase()`，直接 `s_ref.to_lowercase()`。`&String` 也能自動當成 `&str` 傳給 `print_lower(&s6)`。

---

## 一邊念清單、一邊往清單加字

有一次阿凱照著白板上的「待畫清單」一項一項念，念到一半他想：「念到的每一項，我都在**同一塊白板**下面再抄一次！」

小芸馬上阻止：「你在**看**清單的時候，不准同時在上面**寫**。不然清單一直變長，你永遠念不完。先拿張紙記下要加什麼，**念完再一次寫上去**。」

> 這就是常見陷阱：`for x in &v { v.push(*x); }` 會編譯失敗——迴圈持有 `&v`，裡面又要 `&mut v`。解法是先收集要加的東西，迴圈結束後再 push。

## 回到現實：故事 ↔ Rust 對照表

| 故事裡的東西 | 真正的 Rust 概念 |
|------|------|
| 小芸的白板 | **owner** 擁有的值 |
| 走過去看一眼 | **借用** `&` |
| 很多人同時看 | **`&T` 共享借用**（可多個） |
| 唯一的白板筆 | **`&mut T` 獨佔借用** |
| 有人寫時別人不能看 | `&mut` 期間其他借用都不能用 |
| 可擦寫的白板 | owner 宣告為 **`let mut`** |
| 「很多人看，或一個人寫」 | **多讀 XOR 一寫** |
| 看完最後一眼就算離開 | **NLL** |
| 攝影社學長來算字數 | **`calc_len(&s3)`** |
| 借筆給書法社學姊 | **`append_hello(&mut s4)`** |
| 筆暫時遞給學弟再還 | **reborrow** `&mut *outer` |
| 指向待拆教室的紙條 | **dangling reference**（禁止） |
| 送一整塊小白板 | 回傳 **owned `String`** |
| 不用說「走到白板前」 | **auto deref** |
| 一邊念清單一邊加字 | 迴圈中同時 `&v` 與 `&mut v` |

## 一句話記住

> **白板可以很多人一起看，或只讓拿著唯一那支筆的人寫，但不能一邊看一邊寫；借出去的東西一定要還得回來，也不准給人一張指向快要消失的地方的紙條。**
