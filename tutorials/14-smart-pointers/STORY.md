# 故事版：社區活動中心的共用物品 🏘️

> 這篇是**寫給小朋友也看得懂**的故事版。用一個「社區活動中心裡借東西、共用東西」的故事，幫你「感覺」出 `Box`、遞迴型別、`Rc` 與 `Weak`、`RefCell`、`Rc<RefCell<T>>`、`Arc`、`Mutex` 與 `Arc<Mutex<T>>`、`Cow` 是什麼，以及何時用哪一個。故事裡不講程式名詞，名詞都放在 `>` 小框框和最後的對照表裡。先享受故事，別急著背。

---

## 寄放在倉庫的大箱子

小宇家住在一個社區，社區有一間**活動中心**，旁邊是一座大**倉庫**。

小宇有一大箱樂高，房間放不下。他把箱子寄放到倉庫，管理員給他一張**提貨單**。提貨單很小、大小固定，放口袋剛好。箱子**還是小宇一個人的**；他把提貨單送給弟弟，箱子就變成弟弟的。

> 這就是 **`Box<T>`**：把資料放到 heap（倉庫），手上拿一個固定大小的指標（提貨單）。`Box::new(42)` 用起來跟 `42` 本身差不多，`*boxed` 就是「拿提貨單去取貨」。擁有者只有**一個**，送出去就是 move。

## 一箱接一箱的寶藏遊戲

小宇設計了一個**尋寶遊戲**：每個箱子裡放**一個數字**和**下一個箱子的提貨單**，最後一個箱子寫「結束」。

如果他想把「下一個箱子」**整個塞進**這個箱子裡，那箱子裡又要塞一個箱子、又要塞一個……箱子要做多大？**算不出來！**

改放**提貨單**就沒問題了——提貨單大小固定，每個箱子的大小都算得出來。

> 這就是 **遞迴型別需要 Box**：`enum List { Cons(i32, Box<List>), Nil }`。編譯器要知道型別的固定大小；`Box<List>` 只是一個指標，大小固定。程式裡 `List::Cons(1, Box::new(List::Cons(2, Box::new(List::Nil))))`。

## 大家一起看的故事書

活動中心有**一本**很受歡迎的故事書，三戶人家都想看。管理員沒有去影印三本，而是在書旁邊放一本**登記簿**：

- 每多一戶要看，就在登記簿上**加一筆**。
- 某一戶看完了，就**劃掉一筆**。
- 登記簿**歸零**的那一刻，書才收回倉庫。

三戶看的是**同一本書**，而且**誰都不能在上面亂寫**。

> 這就是 **`Rc<T>`**：共享所有權。`Rc::clone(&a)` 只是**在登記簿加一筆**（strong count +1），**不是**影印內容。程式裡建了 `a`、`b`、`c` 後 `Rc::strong_count(&a)` 是 3；`drop(b); drop(c);` 後剩 1。`Rc` 給的內容是**唯讀**的。

### 只記地址、不登記

有一戶只想「**記得**這本書放在哪裡」，但不想算進登記簿。他拿一張**地址便條**。之後想看時去問：「書還在嗎？」還在就換成正式登記；不在了就算了。

> 這就是 **`Weak<T>`**：`Rc::downgrade(&strong)` 拿到不算 strong count 的指標，`weak.upgrade()` 回 `Option<Rc<T>>`。樹狀結構中 child 指 parent 用 `Weak`，避免互相登記、永遠歸不了零（記憶體洩漏）。

### 登記簿只能在同一棟樓用

這本登記簿是用**鉛筆隨手記**的，又快又方便。但管理員規定：**只能在這一棟樓裡用**。如果兩棟樓的人同時搶著改，數字會被記錯。

> 這就是 **`Rc` 只能單執行緒**：`Rc` 的計數不是 atomic，所以它不是 `Send`，編譯器不讓你把它丟到別的 thread。

## 交換日記和借閱牌

活動中心還有一本**交換日記**，大家可以寫東西進去。規則是：

- 可以**很多人同時看**；**或是**一個人在寫。
- **有人在寫的時候，別人不能看、也不能寫。**

這本日記旁邊掛著**借閱牌**。管理員不是在開門前檢查，而是**現場盯著牌子**：有人要寫，就翻成「寫作中」。

有一天，小宇已經翻牌在寫了，他又想**再翻一次牌**同時寫第二份——警鈴立刻**大響**！

> 這就是 **`RefCell<T>`**：借用規則一樣（多讀或一寫），但檢查從**編譯期**改成**執行期**。`*cell.borrow_mut() += 10` 暫時拿到可寫權；`cell.borrow()` 唯讀。程式裡同時兩個 `c.borrow_mut()` 會 **panic**（用 `catch_unwind` 示範）。

---

## 大家共用、又都能寫

把「登記簿」和「借閱牌」**放在一起**：一本大家共用、大家都能寫的交換日記。小宇家寫一筆「4」，鄰居家也寫一筆「5」，打開來看是 `[1, 2, 3, 4, 5]`。

管理員小聲提醒：「這招好用，但**別什麼都用這招**。很多時候，一個人拿著、需要時借給別人寫，就夠了。」

> 這就是 **`Rc<RefCell<T>>`**：單執行緒的「共享 + 可變」。程式裡 `shared_mut.borrow_mut().push(4)`、`other.borrow_mut().push(5)`。README 提醒：寫到 `Rc<RefCell<T>>` 先想想能不能用 owned + `&mut` 避開。

## 好幾棟樓一起用的登記器

社區辦活動，**三棟大樓**的小朋友要同時看同一份活動海報。

鉛筆登記簿不能跨棟用，所以管理員換成一台**防亂按的機械計數器**——不管幾棟樓同時按，數字都不會錯。缺點是按起來**比鉛筆慢一點**。

> 這就是 **`Arc<T>`**：Atomic Rc，API 跟 `Rc` 一樣，計數用 atomic 操作，可以跨 thread。程式裡 `let d = Arc::clone(&data);` 交給三個 `thread::spawn`。跟 `Rc` 一樣，內容是唯讀的。

## 只有一把鑰匙的計分室

活動中心有一間**計分室**，牆上有一塊計分板。房間**只有一把鑰匙**：

- 要改分數，先**拿鑰匙**進去；別人只能在門口等。
- 改完**走出房間，鑰匙自動回到掛鉤上**，下一個人才能進。

十個小朋友從不同大樓過來，每人進去把分數 **+1**。最後計分板剛好是 **10**，一分都沒少。

> 這就是 **`Mutex<T>`** 與 **`Arc<Mutex<T>>`**：`c.lock().unwrap()` 拿鑰匙，拿到 `MutexGuard`，可以當 `&mut T` 用；guard 離開範圍就自動解鎖（RAII）。程式裡 10 個 thread 各 `*c.lock().unwrap() += 1`，`final count = 10`。這是跨 thread「共享 + 可變」的標準組合。注意：同一個人拿著鑰匙又再去拿一次，會卡住（死鎖）。

## 公告：要改才影印

管理員每天要貼公告。他的習慣是：

- 公告**不用改**——直接把**原稿**貼上去，不浪費紙。
- 公告**要改**（例如把空格都換成底線）——才**影印一份**，在影本上改。

> 這就是 **`Cow<T>`（Clone-on-Write）**：`fn process(s: &str) -> Cow<str>`，沒有空格回 `Cow::Borrowed(s)`（零配置），有空格才 `Cow::Owned(s.replace(' ', "_"))`。呼叫端用起來都像 `&str`。

## 該借哪一種？

管理員在門口貼了一張選擇小抄：

- 只是要放倉庫、只有一個主人 → **提貨單**
- 同一棟樓、大家一起看 → **鉛筆登記簿**；還要能寫 → 加上**借閱牌**
- 好幾棟樓、大家一起看 → **機械計數器**；還要能寫 → 加上**一把鑰匙的房間**
- 大多數時候看原稿，偶爾要改 → **要改才影印**

> 這就是 **決策樹**：`Box<T>` → 單一擁有；`Rc<T>` / `Rc<RefCell<T>>` → 單執行緒共享（可變）；`Arc<T>` / `Arc<Mutex<T>>` → 跨執行緒共享（可變）；`Cow<T>` → 多半借用偶爾擁有。**先用 Box，需要共享才升級。**

## 回到現實：故事 ↔ Rust 對照表

| 故事裡的東西 | 真正的 Rust 概念 |
|------|------|
| 寄放倉庫的箱子 + 提貨單 | **`Box<T>`**（heap + 單一擁有者） |
| 箱子裡放下一箱的提貨單 | 遞迴型別 `enum List { Cons(i32, Box<List>), Nil }` |
| 共用故事書 + 登記簿 | **`Rc<T>`**（引用計數） |
| 登記簿加一筆（不是影印） | `Rc::clone(&a)` |
| 數登記簿 | `Rc::strong_count(&a)` |
| 登記簿歸零才收回 | 最後一個 `Rc` drop 才釋放 |
| 只記地址的便條 | **`Weak<T>`** / `upgrade()` |
| 鉛筆登記簿只能同一棟樓 | `Rc` 不是 `Send` |
| 交換日記的借閱牌（現場檢查） | **`RefCell<T>`**（執行期借用檢查） |
| 翻兩次「寫作中」→ 警鈴 | 兩個 `borrow_mut()` → **panic** |
| 大家共用又能寫的日記 | **`Rc<RefCell<T>>`** |
| 跨棟用的機械計數器 | **`Arc<T>`**（atomic 計數） |
| 只有一把鑰匙的計分室 | **`Mutex<T>`** / `lock()` |
| 出門鑰匙自動掛回去 | `MutexGuard` drop 自動解鎖 |
| 十個小朋友輪流 +1 | **`Arc<Mutex<T>>`** |
| 要改才影印的公告 | **`Cow<T>`**：`Borrowed` / `Owned` |

---

## 一句話記住

> **一個主人放倉庫用 `Box`；同一棟樓大家共用用 `Rc`（要寫加 `RefCell`，現場檢查）；跨好幾棟樓共用用 `Arc`（要寫加 `Mutex`，一次一把鑰匙）；要改才影印用 `Cow`。**
