# 故事版：夜市的指路小紙條 🏮

> 這篇是**寫給小朋友也看得懂**的故事版。用一個「逛夜市、拿著小紙條找攤位」的故事，幫你「感覺」出 lifetime 是什麼、為什麼要標 `'a`、struct 裡放借來的東西、elision 規則、`'static`、多個 lifetime、HRTB，以及「不能 dangle」的保證。故事裡不講程式名詞，名詞都放在 `>` 小框框和最後的對照表裡。先享受故事，別急著背。

---

## 指路小紙條

週末，小緯跟爸爸去逛夜市。夜市的攤位**各自有收攤時間**：有的攤位開到半夜，有的九點就收。

小緯的好朋友小晴先到，她寫了一張**小紙條**給小緯：「**去 5 號攤看那個恐龍氣球。**」

紙條上沒有氣球，只寫著「氣球在哪裡」。氣球本身還是**屬於 5 號攤**。

> 這就是 **reference（借用）**：紙條是 `&T`，攤位才是真正的**擁有者**。第 06 章學過：借用不能比擁有者活得久。

---

## 收攤了，紙條就沒用了

問題來了：5 號攤九點就**收攤**，東西全部打包載走。

如果小緯十點才拿著紙條跑去，那裡**什麼都沒有**——紙條指向一個已經不存在的地方。

夜市有一位很認真的**管理員**。他的工作是：**在夜市開門之前**，就先把每一張紙條檢查一遍——「這張紙條**會被用到什麼時候**？它指的攤位**開到什麼時候**？」只要發現有紙條會在攤位收攤後還被拿來用，他就**不讓夜市開門**。

> 這就是 **lifetime 檢查**：`let r; { let x = 5; r = &x; } println!("{r}");` 會編譯失敗——`x` 已經 drop，`r` 還要用。檢查發生在**編譯期**，不是執行到一半才發現。lifetime 不會讓東西多活一秒，它只是讓編譯器**確認**借用沒有超過擁有者。

---

## 兩張紙條，選一張比較長的

小緯手上有兩張紙條，一張指向 A 攤（開到半夜），一張指向 B 攤（開到九點）。爸爸說：「把**寫比較長的那張**給我。」

管理員皺眉：「我在開門前檢查時，**不知道**最後會是哪一張。」

所以他在規則上寫：「你交出來的紙條，**最多只能用到兩個攤位中比較早收攤的那個時間**。」這樣不管選到哪一張，都安全。

> 這就是 **lifetime 標註 `'a`**：`fn longest<'a>(s1: &'a str, s2: &'a str) -> &'a str`。讀作「兩個輸入和輸出至少都活得跟 `'a` 一樣久」，而 `'a` 會被推成兩者中**比較短**的那段。程式裡 `s2` 在內層 `{ }` 裡，所以 `result` 只能在那個大括號裡用，出去就不行。

---

## 標註只是「說好的約定」

小緯問：「那寫上 `'a` 會不會讓 B 攤開久一點？」

管理員笑了：「不會喔。我**寫下來的只是約定**——『這張紙條跟那兩個攤位的關係是這樣』。攤位幾點收，還是攤位自己決定。我只負責**檢查大家有沒有遵守**。」

> 這就是 **lifetime 是 generic 參數、純粹是編譯器約束**：`<'a>` 跟 `<T>` 同一級，不影響型別大小、不影響執行期。標註是**描述關係**，由編譯器驗證。

---

## 推薦卡：夾著別人書裡的一句話

夜市有一個**二手書攤**，擺著一本小說。小緯在一張**推薦卡**上抄了「第一句話在第 1 頁第 1 行」，拿去給朋友看。

推薦卡上沒有書，只有「那句話在哪裡」。所以管理員規定：「這張推薦卡在用的時候，**那本書要一直在書攤上**。」

小緯拿著推薦卡大聲宣布：「我要介紹一句話！」宣布完，他把卡上**指的那句話**唸出來——唸出來的，還是那本書裡的句子。

> 這就是 **struct 持有 reference**：`struct Excerpt<'a> { part: &'a str }`。`novel` 是書，`first_sentence` 是指向書裡的一段，`Excerpt { part: first_sentence }` 就是推薦卡——`novel` 必須活到 `excerpt` 不再使用之後。`announce(&self, msg: &str) -> &str` 回傳的 `self.part` 跟 `self` 同期。如果 struct 想自己帶著東西走，用 `String` 就不用標 lifetime。

---

## 管理員的三條預設規則

大部分紙條其實很簡單，管理員不想每張都叫人寫約定。他有三條**預設規則**：

1. 每張拿進來的紙條，**各自有自己的時間**。
2. 如果**只拿進來一張**，交出去的那張就**跟它一樣久**。
3. 如果是**攤位老闆自己**交出紙條，就**跟老闆的攤位一樣久**。

小緯問：「『把一句話的**第一個字**指給我看』要寫約定嗎？」管理員說：「只拿進來一張，套第 2 條，不用寫。」

> 這就是 **lifetime elision**：`fn first_word(s: &str) -> &str` 等同 `fn first_word<'a>(s: &'a str) -> &'a str`，套規則 2。`Excerpt::announce` 有 `&self`，套規則 3。三條都套不上（像 `longest` 有兩個輸入）才需要手寫。

---

## 刻在大門石頭上的字

夜市入口有一塊大石頭，上面**刻著**「歡迎光臨」。不管哪個攤位收攤，石頭上的字**一直都在**，直到整個夜市拆掉為止。

指向石頭的紙條，**什麼時候拿出來用都可以**。

> 這就是 **`'static`**：`fn forever() -> &'static str { "I live for the entire program" }`。字串字面值存在 binary 裡，整個程式都有效。`T: 'static` 則表示「T 裡沒有短命的借用」，常見於開執行緒。注意：`'static` 不是「常數」，是「可以活到程式結束」。

---

## 紙條清楚寫「只跟第一攤有關」

小緯拿著兩張紙條：A 攤和 B 攤。他寫了一個新規則：「**永遠交出 A 攤那張**。」

既然交出的只跟 A 攤有關，管理員就分開寫：「A 攤一個時間、B 攤另一個時間，交出去的只看 A 攤。」這樣 B 攤早點收也沒關係。

> 這就是 **多個 lifetime**：`fn pick_a<'a, 'b>(a: &'a str, _b: &'b str) -> &'a str`。回傳值只綁 `'a`，跟 `'b` 無關，比全部用同一個 `'a` 更寬鬆。

---

## 不管哪一攤都能量的尺

夜市服務台有一把**量紙條長度的尺**。不管你拿來的紙條指向**哪一攤、那攤幾點收**，它都能量。

> 這就是 **HRTB**：`F: for<'a> Fn(&'a str) -> usize`，唸作「**對所有可能的** `'a`，F 都成立」。程式裡 `apply_to_str(|s: &str| s.len())`。大多數時候編譯器會自動推，寫 callback API 時才偶爾要明寫。

---

## 不能給一張指向「收攤就丟掉的箱子」的紙條

章魚燒攤的老闆想送小緯一張紙條：「**我攤位後面那個箱子**裡有好吃的。」可是老闆收攤時會把那個箱子**丟掉**。

管理員在開門前就攔下來：「不行！你收攤後那箱子就沒了。要嘛**直接把東西送給他**，要嘛給他一張指向**他自己帶來的東西**的紙條。」

> 這就是 **不能 dangle 的編譯期保證**：`fn dangle() -> &String { let s = ...; &s }` 不能編譯，`s` 在函式結束就 drop。改成回傳 owned 的 `String`（直接把東西送他），或 `fn no_dangle<'a>(input: &'a str) -> &'a str`（指向他自己帶來的）。

---

## 回到現實：故事 ↔ Rust 對照表

| 故事裡的東西 | 真正的 Rust 概念 |
|------|------|
| 攤位 | 資料的**擁有者** |
| 指路小紙條 | **reference** `&T` |
| 攤位收攤 | 擁有者 **drop** |
| 開門前檢查所有紙條的管理員 | **borrow checker**（編譯期） |
| 紙條會在收攤後被用 → 不開門 | 編譯錯誤：*doesn't live long enough* |
| 兩張選一張，只能用到較早收攤 | `fn longest<'a>(...) -> &'a str` |
| 約定不會讓攤位開久一點 | lifetime 只是**約束**，不改執行期 |
| 夾著書裡一句話的推薦卡 | `struct Excerpt<'a> { part: &'a str }` |
| 管理員的三條預設規則 | **lifetime elision** |
| 大門石頭上刻的字 | **`'static`** |
| 只跟第一攤有關 | `fn pick_a<'a, 'b>(...) -> &'a str` |
| 哪一攤都能量的尺 | **HRTB** `for<'a> Fn(&'a str)` |
| 指向收攤就丟的箱子 | **dangling reference**（被擋） |
| 直接把東西送給他 | 回傳 owned `String` |

---

## 一句話記住

> **lifetime 就是管理員在夜市開門前檢查：每張紙條都不能在它指的攤位收攤後還被拿來用；`'a` 只是寫下紙條跟攤位的約定，不會讓攤位多開一秒。**
