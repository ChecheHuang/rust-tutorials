# 故事版：果園的水果輸送帶 🍊

> 這篇是**寫給小朋友也看得懂**的故事版。用一個「去果園工廠參觀水果輸送帶」的故事，幫你「感覺」出 `Iterator` 與 `next`、`iter` / `iter_mut` / `into_iter`、lazy、adapter（`filter`、`map`、`take`、`chain`、`zip`…）、consumer（`sum`、`find`、`any`…）、`collect`、`fold`、`flat_map`、自訂 iterator 與 zero-cost 是什麼。故事裡不講程式名詞，名詞都放在 `>` 小框框和最後的對照表裡。先享受故事，別急著背。

---

## 一次只送一顆

校外教學，小芸的班級去參觀**果園工廠**。工廠裡最酷的是一條**輸送帶**。

輸送帶的規矩很簡單：工人按一下按鈕，它就**送出下一顆水果**。水果送完了，它就亮起一盞燈：「**沒了。**」

整座工廠所有厲害的機器，都是靠這個「**按一下、送一顆；沒了就說沒了**」撐起來的。

> 這就是 **`Iterator` trait**：只要實作 `fn next(&mut self) -> Option<Self::Item>`。有東西回 `Some(x)`，沒了回 `None`。上百個方便的 method 都是建立在 `next` 上的 default method。

---

## 看看、貼貼紙、拿走

輸送帶上有一排柳丁。導覽姐姐示範三種處理方法：

1. **只看**：每顆拿起來看看，再放回去，柳丁還是工廠的。
2. **貼貼紙**：每顆貼上「×10 甜度」貼紙——柳丁變了，但還在輸送帶上。
3. **拿走**：每顆直接拿走去榨汁，輸送帶上就**空了**。

> 這就是 **三種 iter**：`nums.iter()` 給 `&i32`（看）；`v.iter_mut()` 給 `&mut i32`，程式裡 `*x *= 10`（貼貼紙）；`v2.into_iter()` 給 `i32`，`v2` 被消耗掉（拿走）。`for x in &v`、`for x in &mut v`、`for x in v` 分別對應這三種。

---

## 機器架好了，沒人按開始

導覽姐姐在輸送帶上架了一台**篩網**（只留偶數號的柳丁）和一台**榨汁機**（把柳丁變成果汁）。

小芸等了好久，機器都**沒有動**。

姐姐說：「因為**還沒有人在最後面接**呀！要有人在尾巴說『我要裝瓶』或『我要算總共幾杯』，整條線才會開始跑。」

> 這就是 **lazy（惰性求值）**：`filter`、`map`、`take`、`skip`、`chain` 都是 **adapter**，架好了也不會自己跑，直到有 **consumer**（`collect`、`sum`、`count`、`for`、`fold`…）來拉。好處是串一百台機器，中間也不會多出一百個暫存的箱子。忘了接 consumer，編譯器會警告。

---

## 篩網接榨汁機，最後算總量

姐姐按下開始：柳丁一顆顆過**篩網**，只留偶數號的；再進**平方機**（偶數號的柳丁變成號碼平方那麼多毫升）；最後全部倒進一個**量杯**加總。

2、4、6、8、10 號柳丁 → 4 + 16 + 36 + 64 + 100 = **220** 毫升。

> 這就是 **adapter chain**：`nums.iter().filter(|&&x| x % 2 == 0).map(|&x| x * x).sum()`，結果 220。`filter` 是篩網、`map` 是平方機、`sum` 是量杯。

---

## 各種工作站

輸送帶旁邊還有好多小工作站：

- **只拿前 5 顆**、**跳過前 3 顆**、**每 3 顆拿 1 顆**
- 把**兩條輸送帶接起來**變一條長的
- 把**兩條輸送帶並排**，每次各拿一顆配成一對（短的那條送完就停）
- **編號機**：每顆水果貼上「第 0 顆、第 1 顆……」

甚至有一條**永遠不會停**的輸送帶，水果無限送——但只要接上「只拿前 5 顆」，就會乖乖停下來。

> 這就是 **常用 adapter**：`take(5)`、`skip(3)`、`step_by(3)`、`a.iter().chain(b.iter())`、`a.iter().zip(b.iter())`、`enumerate()`。程式裡 `(1..).take(5)` 就是從無限輸送帶拿前 5 個。

---

## 最後面的人在問什麼

輸送帶尾巴的人，可以問各種問題：

- 「**總共**多重？」「全部**乘起來**？」「**最大**最小的是幾號？」「總共**幾顆**？」
- 「**第一顆**偶數號的是誰？」
- 「**有沒有** 7 號？」「是不是**全部**都是正數號？」
- 「5 號排在**第幾個**位置？」

有些問題一找到答案就**立刻停下輸送帶**，不用全部跑完。

> 這就是 **consumer**：`sum()`、`product()`、`max()`、`min()`、`count()`、`find(...)`、`any(...)`、`all(...)`、`position(...)`。`find`、`max` 這類可能沒有答案的，回 `Option`。

---

## 你拿什麼箱子，就裝成什麼樣

裝瓶區的叔叔說：「你給我**長條箱**，我就一瓶瓶排好；你給我**標籤櫃**，我就把『號碼 → 果汁量』一格格放進去。」

> 這就是 **`collect`**：看**目標型別**決定裝成什麼。`let doubled: Vec<i32> = ...collect();`、`let hash: HashMap<i32, i32> = nums.iter().map(|&x| (x, x * x)).collect();`。`Result` 的輸送帶還能 collect 成 `Result<Vec<T>, E>`，遇到第一個錯就停。

---

## 滾雪球的撲滿

小芸的弟弟拿著一個**撲滿**站在尾巴。撲滿一開始是 **0 元**，每來一顆水果，他就把「撲滿裡的錢 + 這顆水果的號碼」當成**新的撲滿金額**。全部跑完，撲滿剛好是 55。

姐姐說：「撲滿裡不一定要放錢，也可以放一張紙條，每來一顆就**在紙條後面加上逗號和號碼**。」

> 這就是 **`fold`**：`nums.iter().fold(0, |acc, &x| acc + x)` 得到 55；程式裡也用 `fold(String::new(), ...)` 組出 `"1,2,3,..."` 的 csv。`fold(初始值, 怎麼把下一顆加進去)` 幾乎什麼累積都能做。

---

## 把一串葡萄拆成一顆顆

另一條線送的是**一串一串的葡萄**。工人用**拆串機**把每一串拆開，變成一顆顆葡萄，再送到下一站。

> 這就是 **`flat_map`**：`words.iter().flat_map(|s| s.split(' '))`，把 `"hello world"`、`"rust is fun"` 兩句拆成一個個單字，攤平成一條。

---

## 自己做一台會生水果的機器

小芸回家後，用紙箱做了一台「**自己會生出下一顆**」的機器。它心裡記著**兩個數字**：每按一下，就送出第一個數字，然後把兩個數字往前推（新的數字是兩個相加）。

0、1、1、2、3、5、8……這台機器**永遠不會說「沒了」**，所以她接上「只拿前 10 顆」。

更棒的是：因為她的機器會「按一下送一顆」，工廠裡**所有工作站都能直接接上去用**。

> 這就是 **自訂 Iterator**：`struct Fibonacci { a: u64, b: u64 }`，`impl Iterator for Fibonacci { type Item = u64; fn next(&mut self) -> Option<u64> { ... Some(cur) } }`。只寫 `next`，就**免費**得到 `map`、`filter`、`take`、`collect`…… 程式裡 `Fibonacci::new().take(10).collect()`。

---

## 跟手工一樣快

小芸問：「串這麼多機器，會不會比一顆顆**用手做**還慢？」

廠長笑著說：「工廠在開工前會把整條線**重新規劃好**，實際跑起來，跟老師傅一顆一顆手工做**一樣快**。」

> 這就是 **zero-cost abstraction**：`(0..1_000_000).map(|x| x * x).sum()` 跟手寫 `for` 迴圈編譯出來幾乎一樣。寫 iterator 風格不會比較慢。

## 回到現實：故事 ↔ Rust 對照表

| 故事裡的東西 | 真正的 Rust 概念 |
|------|------|
| 按一下送一顆，沒了亮燈 | **`Iterator::next`** → `Some` / `None` |
| 只看 / 貼貼紙 / 拿走 | `iter()` / `iter_mut()` / `into_iter()` |
| 機器架好但沒人在尾巴接 | **lazy**：adapter 不會自己跑 |
| 篩網、平方機 | `filter`、`map`（adapter） |
| 尾巴的量杯 | `sum()`（consumer） |
| 拿前幾顆、跳過、每 3 顆拿 1 顆 | `take` / `skip` / `step_by` |
| 兩條接一條 / 並排配對 / 編號機 | `chain` / `zip` / `enumerate` |
| 無限輸送帶 + 只拿前 5 顆 | `(1..).take(5)` |
| 尾巴的人問問題 | `count`、`max`、`find`、`any`、`all`、`position` |
| 拿什麼箱子就裝成什麼 | **`collect`**（看目標型別） |
| 滾雪球的撲滿 | **`fold`** |
| 拆串機 | **`flat_map`** |
| 自己做的會生水果機器 | **自訂 `impl Iterator`**（`Fibonacci`） |
| 跟手工一樣快 | **zero-cost abstraction** |

---

## 一句話記住

> **Iterator 就是一條「按一下送一顆、沒了說沒了」的輸送帶：中間架篩網和機器（adapter）不會自己動，要有人在尾巴接（consumer）才開跑；自己的機器只要會 `next`，整座工廠的工作站都能接。**
