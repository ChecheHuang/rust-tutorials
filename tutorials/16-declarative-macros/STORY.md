# 故事版：卡片工作室的魔法印章 🖨️

> 這篇是**寫給小朋友也看得懂**的故事版。用一個「在卡片工作室用魔法印章做卡片」的故事，幫你「感覺」出 `macro_rules!`、pattern 與展開、fragment specifier、多個 arm、repetition 與遞迴、產生 struct / impl、小型 DSL、衛生規則、`stringify!` 是什麼，以及何時該用函式就好。故事裡不講程式名詞，名詞都放在 `>` 小框框和最後的對照表裡。先享受故事，別急著背。

---

## 印章不是幫手，是「先蓋好」

小樂的阿姨開了一間**卡片工作室**。工作室裡有兩種幫忙的方式：

- **幫手**：卡片寄出去之後，收到卡片的人再照著上面的指示做事。
- **魔法印章**：在卡片**送去印刷之前**，就把一大段字**直接蓋到卡片上**。印刷廠拿到的，已經是蓋好的完整卡片。

阿姨說：「印章厲害的地方是——它看的是你**寫了什麼字、排成什麼形狀**，然後照形狀蓋出一大段內容。」

> 這就是 **macro**：在**編譯期**展開，操作的是程式碼的「形狀」（token / 語法樹），不是執行時的值。函式（幫手）是執行時才跑。宏的名字後面都有 `!`，像 `println!`、`vec!`。

---

## 最簡單的印章

阿姨給小樂第一顆印章，上面刻著：「**不用給任何東西，蓋下去就出現『Hello！』**」

小樂往卡片上一蓋——「Hello from macro!」

> 這就是 **最簡單的 `macro_rules!`**：`macro_rules! say_hello { () => { println!("Hello from macro!"); }; }`。`()` 是「不吃任何東西」，`=>` 右邊是要蓋出來的內容。`say_hello!();` 展開成那行 `println!`。

---

## 印章上的空格，標著要填什麼

第二顆印章上有一個**空格**，旁邊標著「**這格填一個算式**」。蓋出來是「（算式）乘以（算式）」。

小樂填「5」，蓋出「5 × 5」。他又調皮地填「2 + 3」——擔心會蓋成「2 + 3 × 2 + 3」算錯。

阿姨說：「放心，印章會把你填的**整個算式包成一包**，蓋出來是『(2 + 3) × (2 + 3)』，等於 25。」

> 這就是 **帶參數的 macro 與 `$x:expr`**：`macro_rules! square { ($x:expr) => { $x * $x }; }`。`$x` 是空格的名字，`:expr` 是「這格填 expression」。`square!(2 + 3)` 會得到 25，因為 `$x` 被當成一整個 expression。

### 不同的空格標籤

阿姨的印章櫃裡，空格有各種標籤：

- 「填**名字**」——像 `Point`、`x`
- 「填**算式**」——像 `1 + 1`
- 「填**種類**」——像 `i32`、`String`
- 「填**一塊東西**」——什麼都能填，最寬鬆，但出錯時最難找原因

> 這就是 **fragment specifier**：`ident`（識別字）、`expr`（expression）、`ty`（型別）、`tt`（token tree，最寬鬆）等等，還有 `pat`、`block`、`literal`、`path`、`item`… 越具體的標籤越好。

---

## 一顆印章，好幾種蓋法

第三顆印章叫「**偵錯章**」，它會先看你給了什麼，**由上往下**找第一種符合的蓋法：

1. **什麼都沒給** → 蓋出「(no args)」
2. **給一樣東西** → 蓋出「你寫的字 = 它的值」，例如「1 + 1 = 2」
3. **給好幾樣東西** → 對**每一樣**都再蓋一次第 2 種

> 這就是 **多個 arm**：`macro_rules! debug { () => {...}; ($val:expr) => {...}; ($($val:expr),+ $(,)?) => { $(debug!($val);)+ }; }`，跟 `match` 一樣由上往下比對。`debug!()`、`debug!(42)`、`debug!("hello", 3.14, [1, 2, 3])` 各走不同 arm。

### 把你寫的字原樣印出來

偵錯章蓋出「1 + 1 = 2」時，左邊的「1 + 1」不是算出來的，而是把你**寫在空格裡的字原封不動**印出來。

> 這就是 **`stringify!($val)`**：把 token 原樣變成字串，debug 訊息很好用。

---

## 一直重複，直到用完

第四顆印章叫「**找最小章**」，可以填**很多個**數字，用逗號隔開。

它的蓋法很聰明：

- 如果**只有一個數字** → 那就是它。
- 如果**有好幾個** → 蓋出「第一個」和「**剩下那些再蓋一次找最小章**的結果」比，取小的。

就這樣一層一層，直到只剩一個數字為止。3、1、4、1、5、9、2、6 → **1**。

> 這就是 **repetition 與遞迴 macro**：`$($rest:expr),+` 表示「一個以上、用逗號分隔」（`*` 是零個以上、`?` 是零或一個）。`my_min!` 的第二個 arm 展開成 `std::cmp::min($x, my_min!($($rest),+))`。**一定要有 base case**（只剩一個的那一 arm），不然會無限展開。

---

## 印章直接印出一張新表格

第五顆印章最神奇：你填「**表格名字**」和「**欄位：種類**」，它就**直接印出一整張新表格**。

小樂填「Point，x：數字，y：數字」，就多了一張 Point 表格；再填「Person，name：文字，age：數字，」——最後多打一個逗號也沒關係。

> 這就是 **用 macro 產生 struct**：`create_struct!(Point { x: i32, y: i32 });`，matcher 是 `($name:ident { $($field:ident : $ty:ty),* $(,)? })`。`$(,)?` 允許結尾多一個逗號。函式做不到這種事——函式不能「生出新的型別」。

---

## 一次幫好多種卡片蓋上同一段說明

工作室有好幾種卡片，每種都要附上一段**一模一樣格式**的「自我介紹說明」。手寫好幾遍太累了。

阿姨刻了一顆章：「**填卡片種類，就蓋出那種卡片的自我介紹說明。**」

> 這就是 **用 macro 產生 impl**：`impl_display_via_debug!(Wrapped);` 展開成 `impl std::fmt::Display for Wrapped { ... write!(f, "{:?}", self) }`，用 `$name:ty` 接型別。重複的 boilerplate 最適合交給 macro。

---

## 發明自己的寫法

小樂想做一張「名字 → 分數」的成績卡。他覺得一般寫法太長，於是發明了**自己的寫法**：

「alice => 95, bob => 80, carol => 88」

阿姨幫他刻了一顆章，專門看懂這種寫法，蓋出一張填好的成績卡。

> 這就是 **小型 DSL**：`map! { "alice" => 95, "bob" => 80, "carol" => 88 }`，matcher 是 `($($key:expr => $val:expr),* $(,)?)`，展開成建立 `HashMap` 再一個個 `insert`。大家常用的 `vec![1, 2, 3]`、`vec![0; 5]` 也是這樣用 `macro_rules!` 做出來的。

---

## 印章裡的草稿紙，不會跑到你桌上

小樂發現一件事：有一顆印章蓋的時候，自己內部用了一張叫「x」的**草稿紙**。蓋完後，小樂在桌上找「x」——**找不到**。

阿姨說：「印章裡用的草稿紙，**留在印章裡**，不會跑到你的桌上；你桌上本來的東西，印章也不會偷偷拿走。這樣才不會亂掉。」

> 這就是 **衛生規則（hygiene）**：macro 裡 `let x = 5;` 宣告的變數不會洩漏到呼叫端。這跟 C 的 `#define` 純文字替換很不一樣。但透過 `$x` 傳進去的名字，還是屬於呼叫端。

---

## 能用幫手，就別刻印章

小樂迷上刻印章，什麼都想刻。阿姨提醒他：

「印章難刻、出錯時也難查。只是**算算數字**這種事，請幫手（函式）做就好。只有在**數量不固定**、要**蓋出新表格或說明**、或想**發明自己的寫法**時，才刻印章。」

「如果不確定印章蓋出來長什麼樣，就用**透明預覽片**看一下蓋完的樣子。」

> 這就是 **何時用 macro**：優先用函式；參數數量浮動、要產生型別或 impl、要做 DSL 時才用 macro。`cargo expand` 可以看展開後的程式碼。要給別的 module 用，記得 `#[macro_export]`。

## 回到現實：故事 ↔ Rust 對照表

| 故事裡的東西 | 真正的 Rust 概念 |
|------|------|
| 送印刷前先蓋好的魔法印章 | **macro**（編譯期展開） |
| 寄出後才做事的幫手 | **函式**（執行期） |
| 不用給東西就蓋出 Hello | `say_hello!()`，matcher 是 `()` |
| 印章上的空格 | `$x` |
| 空格旁的標籤 | **fragment specifier**：`expr`、`ident`、`ty`、`tt`… |
| 填的算式會包成一包 | `square!(2 + 3)` = 25 |
| 一顆印章好幾種蓋法、由上往下找 | **多個 arm**（`debug!`） |
| 把寫的字原樣印出 | **`stringify!`** |
| 一直重複直到用完 | **repetition** `$(...),+` / `*` / `?` |
| 剩下的再蓋一次、只剩一個就停 | **遞迴 macro** + base case（`my_min!`） |
| 結尾多一個逗號沒關係 | `$(,)?` |
| 直接印出新表格 | 產生 struct（`create_struct!`） |
| 幫好多卡片蓋同樣說明 | 產生 impl（`impl_display_via_debug!`） |
| 發明自己的「名字 => 分數」寫法 | **DSL**（`map!`） |
| 印章裡的草稿紙不會跑出來 | **hygiene** |
| 透明預覽片 | `cargo expand` |

---

## 一句話記住

> **`macro_rules!` 是送印刷前就蓋好的魔法印章：照你寫的形狀比對（像 `match`），空格標好要填什麼，能重複、能遞迴、能蓋出新表格和說明；但能用函式解決的，就別刻印章。**
