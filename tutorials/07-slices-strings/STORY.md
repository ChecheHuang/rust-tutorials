# 故事版：串珠教室的手鍊與小夾子 📿

> 這篇是**寫給小朋友也看得懂**的故事版。用一個「去手作教室串字母手鍊」的故事，幫你「感覺」出 `String` 與 `&str`、`Vec<T>` 與 `&[T]`、切片是「起點＋長度」、字串方法、UTF-8 一個字好幾顆珠、切片要切在字的邊界、字串不能用 `[0]` 拿字，以及三種把 `&str` 變成 `String` 的方法。故事裡不講程式名詞，名詞都放在 `>` 小框框和最後的對照表裡。先享受故事，別急著背。

---

## 自己的手鍊和展示櫃的樣品

小莉來到珠珠老師的串珠教室。牆上的**玻璃展示櫃**裡，有一條樣品手鍊，串著「hello」五顆字母珠。

老師說：「展示櫃裡的樣品**永遠都在**，大家都能看，但**不能拿出來改**。」

然後老師給小莉一條**可以加長的彈力繩**：「這條是**你自己的**，你想加幾顆珠子都可以。」小莉先串上「hi」。

> 這就是 **`&str` 與 `String`**：`let literal: &str = "hello";` 是字串字面值，存在程式本身裡，一直都在（`'static`），唯讀。`let owned: String = String::from("hi");` 放在 heap，**自己擁有、可以修改**。

---

## 一個小夾子：從哪裡開始、夾幾顆

老師給每個人幾個**小夾子**。夾子不是珠子，它只是夾在手鍊上，告訴你「**從這一顆開始，看幾顆**」。

小莉把夾子夾在自己的手鍊上，從第 0 顆開始夾 1 顆——夾到「h」。她也可以夾**整條**。

夾子很輕，借給別人看很方便，**不用重串一條**。

> 這就是 **slice 是 fat pointer**：`&str` 只有兩個東西——**起點**（ptr）和**長度**（len），自己不擁有資料。`let slice: &str = &owned;` 夾整條，`let part: &str = &owned[0..1];` 夾一段。`String` 則多一個 cap（彈力繩還能撐多長）。

---

## 往自己的手鍊上加珠子

小莉的手鍊上現在是「hello」。她：

- 加上**一顆**空白珠
- 再加上**一串**「world」
- 最後再加**一串**「!」

變成「hello world!」。只有她**自己的**彈力繩可以這樣加，展示櫃裡的樣品不行。

> 這就是 **`String` 的修改方法**：`s.push(' ')` 加一個字元，`s.push_str("world")` 加一段字串，`s += "!"` 等同 `push_str`。

### 用夾子挑出前半和後半

小莉把「hello world」用兩個夾子分開看：一個夾**前 5 顆**，另一個從**第 6 顆夾到最後**。

> 這就是 **字串子切片**：`let hello = &s[..5]; let world = &s[6..];`。`..5` 是「從頭到第 5 顆前」，`6..` 是「從第 6 顆到結尾」。

---

## 數字珠盒和數字手鍊

教室另一邊有一個**固定五格的數字珠盒**：10、20、30、40、50。盒子格子是固定的，不能多也不能少。

小莉用夾子**從第 1 格夾到第 4 格之前**，看到 20、30、40。

另外她還有一條**數字彈力繩** 1、2、3，可以一直加、一直拿掉。夾子也可以夾在這條上，一次夾**全部**。

> 這就是 **`&[T]` 與 `Vec<T>`**：`let slice: &[i32] = &arr[1..4];` 得到 `[20, 30, 40]`；`let v_slice: &[i32] = &v[..];` 夾整段。`Vec<T>` 像彈力繩，可以 push / pop；`&[T]` 只是夾子，只能看（`&mut [T]` 可以換掉某顆，但不能加長）。

---

## 中文字要用三顆珠子

小莉想串「**你好**」。老師拿出一盒特別的珠子：「英文字母一顆珠就是一個字，可是**中文一個字要三顆珠子**黏在一起才算。」

串好之後，小莉數了數：手鍊上有 **6 顆珠子**，但只有 **2 個字**。

> 這就是 **UTF-8**：`String` 裡面存的是 UTF-8 bytes。`zh.len()` 是 **6**（bytes，也就是珠子數），`zh.chars().count()` 才是 **2**（字數）。`len()` **不是**字數！

### 夾子一定要夾在字的邊界上

小莉用夾子夾「前 3 顆」，剛好是完整的「**你**」，沒問題。

接著她手一滑，想夾「前 **1** 顆」——那是「你」這個字的**三分之一**。老師馬上大喊：「**停！**這樣會把字夾壞！」整個教室停下來。

> 這就是 **切片必須在 char 邊界**：`&zh[..3]` 得到 `"你"`；`&zh[..1]` 會在**執行時 panic**：byte index 1 is not a char boundary。要安全取前幾個字，用 `zh.chars().take(n).collect::<String>()`，或先用 `is_char_boundary` 檢查。

---

## 不能說「給我第 0 顆」就當作一個字

小莉問老師：「我可以直接說『**給我第 0 個字**』嗎？」

老師說：「我的珠子是一顆一顆編號的，如果你要的是第 0 顆**珠子**，我給你；可是第 0 顆珠子**不一定是一整個字**，它可能只是中文字的一小塊。所以要『一個字』的話，你得說『**從頭開始，一個字一個字數，給我第一個**』。」

> 這就是 **`&str` 不能索引**：`s[0]` 會編譯失敗。要第一個字元用 `s.chars().next()`（程式裡 `zh.chars().next()` 得到 `Some('你')`）；真的要第一個 byte 才用 `s.as_bytes()[0]`。

---

## 照著樣品做一條自己的

小莉很喜歡展示櫃裡的「hi」樣品，想要一條**自己的**。

她問了三位助教，三個人說法不同：

- 「把它**變成手鍊**。」
- 「**用**它**做**一條手鍊。」
- 「做一條**自己擁有**的。」

結果三位做出來的手鍊**一模一樣**。

> 這就是 **三種 `&str` → `String`**：`"hi".to_string()`、`String::from("hi")`、`"hi".to_owned()`，結果完全相同（程式印出 `equal: true true true`）。挑一個風格用到底就好。

---

## 老師的工具桌

工具桌上有幾樣好用的東西：

- **剪刀**：在每顆「,」逗號珠的位置分段——「a,b,c,d」變成四段。剪完的每一段其實是**夾子**，還夾在原本那條上。
- **珠子翻譯機**：把串著「42」的手鍊，翻成一個真正的**數字 42**。
- **換珠機**：把「foo bar」裡的 foo 換成 baz，做出**一條新的**手鍊。
- **修邊器**：把手鍊頭尾多餘的空白珠夾掉。

> 這就是 **常用字串方法**：`csv.split(',').collect::<Vec<&str>>()`（每段是 `&str`，指回原字串）、`"42".parse::<i32>()`、`"foo bar".replace("foo", "baz")`（回傳新的 `String`）、`"   spaces   ".trim()`（回傳 `&str`）。

---

## 找第一個詞，只要給夾子

最後老師出題：「寫一張說明，**找出手鍊上的第一個詞**。」

小莉想了想：「我不用重新串一條，**給一個夾子**夾住第一個詞就好。而且這張說明不管是用在**我自己的手鍊**，還是**展示櫃的樣品**，都能用。」

老師點頭：「所以說明上要寫『**請給我一個夾子**』，不要寫『請給我一條手鍊』，這樣誰都能用。」

> 這就是 **函式參數 prefer `&str`**：`fn first_word(s: &str) -> &str { s.split_whitespace().next().unwrap_or("") }`。`first_word(&owned_string)` 和 `first_word(literal)` 都能呼叫，因為 `&String` 會自動變成 `&str`。回傳的也是夾子，不用配置新字串。

## 回到現實：故事 ↔ Rust 對照表

| 故事裡的東西 | 真正的 Rust 概念 |
|------|------|
| 展示櫃裡的樣品手鍊 | **字串字面值** `&'static str` |
| 自己的彈力繩手鍊 | **`String`**（heap、可修改） |
| 彈力繩還能撐多長 | **capacity** |
| 小夾子（起點＋幾顆） | **slice** `&str` / `&[T]`（ptr + len） |
| 加一顆 / 加一串 | **`push`** / **`push_str`** / `+=` |
| 夾前 5 顆、從第 6 顆到最後 | **`&s[..5]`**、**`&s[6..]`** |
| 固定五格數字珠盒 | **陣列** `[i32; 5]` |
| 數字彈力繩 | **`Vec<T>`** |
| 一顆珠子 | **byte**（`u8`） |
| 中文字三顆珠 | **UTF-8** 多 byte 字元 |
| 數珠子 vs 數字 | **`len()`** vs **`chars().count()`** |
| 把字夾壞，老師喊停 | 非 char 邊界切片 → **panic** |
| 不能說「第 0 個字」 | `&str` **不能索引**，用 `chars().next()` |
| 照樣品做自己的 | `to_string` / `String::from` / `to_owned` |
| 剪刀、翻譯機、換珠機、修邊器 | `split` / `parse` / `replace` / `trim` |
| 「請給我一個夾子」的說明 | **`fn first_word(s: &str) -> &str`** |

## 一句話記住

> **`String` 是你自己的、可以一直加珠的手鍊，`&str` 只是一個夾子（從哪開始、夾幾顆）；數 `len()` 數的是珠子不是字，中文一個字三顆珠，夾子一定要夾在字的邊界上；寫說明時跟人要夾子（`&str`），誰的手鍊都能用。**
