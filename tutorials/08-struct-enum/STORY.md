# 故事版：園遊會的尋寶大作戰 🗺️

> 這篇是**寫給小朋友也看得懂**的故事版。用一個「校慶園遊會玩尋寶遊戲」的故事，幫你「感覺」出具名 struct、tuple struct、unit struct、`impl` 裡的關聯函式和方法、`self` 的三種形式、struct update、enum 帶不同資料、`match` 窮盡、`Option<T>`、`#[derive]`、`Display` 和解構是什麼。故事裡不講程式名詞，名詞都放在 `>` 小框框和最後的對照表裡。先享受故事，別急著背。

---

## 寫好欄位的位置卡

校慶園遊會的尋寶遊戲開始了！阿寶到報到櫃台，主持人陳老師給他一張**位置卡**，上面印好兩個欄位：

> **橫：___　直：___**

阿寶在「橫」填 3、在「直」填 4。不管誰拿到這張卡，一看欄位名稱就知道哪個數字代表什麼。

> 這就是 **具名欄位的 struct**：`struct Point { x: i32, y: i32 }`，用 `Point { x: 3, y: 4 }` 建立，用 `p.x`、`p.y` 讀。最常見的形態。

---

## 只有三個數字的旗子卡

每一隊還有一張**隊旗顏色卡**，上面只有三格數字：**255、128、0**。卡片上沒寫「紅、綠、藍」，大家約好**第一格是紅、第二格是綠、第三格是藍**，照順序讀就好。

> 這就是 **tuple struct**：`struct Rgb(u8, u8, u8);`，沒有欄位名，用 `color.0`、`color.1`、`color.2` 讀。

### 裝在不同顏色信封裡的數字

園遊會的跳遠攤記「幾公尺」，舉重攤記「幾公斤」。兩個都只是一個數字，很容易搞混。陳老師就規定：公尺裝**藍信封**、公斤裝**紅信封**——信封不一樣，就**不可能**拿錯。

> 這就是 **newtype pattern**：`struct Meters(f64); struct Kilograms(f64);`。底下都是 `f64`，但編譯器把它們當成**不同型別**，不會讓你把公斤傳給要公尺的地方。

---

## 什麼都沒寫的參加徽章

每個人還拿到一個**參加徽章**。徽章上**什麼資料都沒有**，它的意思只有一個：「**我有參加**。」

> 這就是 **unit struct**：`struct Marker;`，沒有欄位、大小是 0。程式裡 `let _m = Marker;`。常用來當「標記型別」。

---

## 櫃台開卡、自己移動

**開新卡**要去櫃台。阿寶說：「請給我一張『橫 3、直 4』的卡。」或是說：「請給我一張**起點卡**。」櫃台直接做一張給他——這件事**不需要先有一張卡**。

拿到卡之後，就是阿寶**自己的事**了。陳老師廣播：「所有人**往右 1 步、往上 1 步**！」阿寶就在自己的卡上把 3 改 4、4 改 5。

他想知道離起點多遠，就拿自己的卡和起點卡**比一比、量一量**——量的時候兩張卡都**只是看**，誰也沒被改。

> 這就是 **`impl` 裡的關聯函式與方法**：`Point::new(3, 4)`、`Point::origin()` 沒有 `self`，用 `::` 呼叫（像櫃台）；`p.translate(1, 1)` 是 `&mut self`，會改自己；`p.distance_to(&origin)` 是 `&self`，只讀。`Self` 就是「這個 impl 的型別」，`Self { x, y }` 等於 `Point { x, y }`。

### 把卡交出去換獎品

遊戲最後，阿寶可以把位置卡**交給櫃台換獎品**。交出去之後，卡就**不是他的了**，他也不能再改或再量。

> 這就是 **`self` 的三種形式**：`fn m(&self)` 只看、`fn m(&mut self)` 修改、`fn m(self)` **拿走所有權**（消費掉這個值，例如 builder 的收尾）。

---

## 兩種唸卡片的方法

阿寶要跟隊友報位置。他可以用**漂亮的方式**唸：「**(4, 5)**」；也可以用**工程師的方式**唸：「Point，x 是 4，y 是 5」。

工程師唸法有一個**現成的印章**，蓋一下卡片就自動會唸。漂亮唸法則是陳老師**親手寫**了一張說明，規定「括號、逗號、空格」怎麼排。

> 這就是 **`Debug` 與 `Display`**：`#[derive(Debug)]` 讓 `{p:?}` 自動能印；`{p}` 要自己 `impl fmt::Display for Point`，用 `write!(f, "({}, {})", self.x, self.y)` 決定格式。

### 一排現成的印章

櫃台還有好多印章：「**可以複製**」「**可以比較一不一樣**」「**可以排大小**」「**可以當寄物櫃號碼**」……想要哪個功能，就在卡片上方蓋哪個章。

> 這就是 **`#[derive(...)]`**：`Debug`、`Clone`、`Copy`、`PartialEq` / `Eq`、`PartialOrd` / `Ord`、`Hash`、`Default`。本章的 `Point` 是 `#[derive(Debug, Clone)]`。注意 `Copy` 要所有欄位都能 Copy，裡面有 `String` 就蓋不上去。

## 複印一張，只改一格

小柚的卡是「橫 1、直 2」。阿寶說：「我想要一張**跟你一樣**，只是**橫改成 99** 的卡。」

櫃台把小柚的卡**照著抄**，只把「橫」改成 99，其他格**照抄**。

> 這就是 **struct update syntax**：`let p2 = Point { x: 99, ..p1 };`。`..p1` 是「剩下的欄位從 p1 拿」。這裡 `y` 是 `i32` 會被複製；如果被拿的欄位不是 Copy（例如 `String`），就會從 `p1` **move** 過去。

---

## 四種形狀的寶箱

找到寶箱了！寶箱有**四種形狀**，每一種貼的資料都不一樣：

- **圓形寶箱**：貼著「半徑 1」
- **方形寶箱**：貼著兩個數字「3 和 4」
- **三角形寶箱**：貼著三個數字「3、4、5」
- **空寶箱**：什麼都沒貼

每個寶箱都**只會是其中一種**。陳老師要大家算「寶箱底部有多大」，並且規定：「**四種形狀你都要會算**，漏掉一種，這份答案卷我就不收。」

> 這就是 **enum（sum type）**：`enum Shape { Circle { radius: f64 }, Rect(f64, f64), Triangle(f64, f64, f64), Empty }`，每個 variant 可以帶不同形狀的資料。`Shape::area(&self)` 裡用 `match self { ... }` 處理每一種，**漏一種就編譯失敗**；以後加新形狀，所有 match 都會被編譯器揪出來補。

---

## 打開來可能是空的

最後的大獎是一排**扭蛋**。每顆扭蛋打開只有兩種結果：

- **裡面有東西**，例如一張「7 點」點數卡
- **空的**

陳老師說：「這裡**沒有**『說不清楚到底有沒有』的扭蛋。打開之前，你**一定要想好**兩種情況怎麼辦。」

> 這就是 **`Option<T>`**：`enum Option<T> { Some(T), None }`。Rust **沒有 null**，可能沒有的值就用 `Option`，例如 `let some: Option<i32> = Some(7); let none: Option<i32> = None;`。

### 處理扭蛋的幾種方法

- **空的就給安慰獎**：拿到空扭蛋，送你「-1 點」安慰卡。
- **有的話就加倍**：有點數就變兩倍，空的還是空的。
- **有的話再檢查一下**：點數要大於 0 才算數，不然就當作空的。

> 這就是 **Option 常用方法**：`none.unwrap_or(-1)` → `-1`；`some.map(|x| x * 2)` → `Some(14)`；`some.and_then(|x| if x > 0 { Some(x) } else { None })` 讓下一步自己也能回傳 `Option`。`unwrap()` 是「我保證不是空的，是空的就大叫停下來」，要小心用。

---

## 拆開卡片

活動結束，阿寶把位置卡「橫 10、直 20」**一格一格拆開**，分別抄到兩張小紙條上：一張寫 10，一張寫 20。

> 這就是 **解構（destructure）**：`let Point { x, y } = p;` 一次拿出所有欄位；`let (a, b) = (1, 2);` 是 tuple 解構。也可以 `Point { x, .. }` 只拿部分欄位。

## 回到現實：故事 ↔ Rust 對照表

| 故事裡的東西 | 真正的 Rust 概念 |
|------|------|
| 印好欄位的位置卡 | **具名 struct** `Point { x, y }` |
| 只有三格數字的旗子卡 | **tuple struct** `Rgb(u8, u8, u8)` |
| 藍信封公尺、紅信封公斤 | **newtype** `Meters(f64)` / `Kilograms(f64)` |
| 什麼都沒寫的參加徽章 | **unit struct** `Marker` |
| 櫃台開新卡 | **關聯函式** `Point::new` / `Point::origin` |
| 自己在卡上移動 | **`&mut self`** 方法 `translate` |
| 兩張卡比一比量距離 | **`&self`** 方法 `distance_to` |
| 交卡換獎品 | **`self`**（拿走所有權） |
| 工程師唸法的印章 | **`#[derive(Debug)]`** / `{:?}` |
| 老師手寫的漂亮唸法 | **`impl fmt::Display`** / `{}` |
| 一排現成印章 | **`#[derive(Clone, PartialEq, ...)]`** |
| 照抄只改一格 | **struct update** `..p1` |
| 四種形狀的寶箱 | **enum** `Shape` |
| 四種都要會算才收卷 | **`match` 窮盡** |
| 有東西或空的扭蛋 | **`Option<T>`**（`Some` / `None`） |
| 空的給安慰獎 | **`unwrap_or`** |
| 有的話加倍 | **`map`** |
| 有的話再檢查 | **`and_then`** |
| 一格一格拆開卡片 | **解構** `let Point { x, y } = p` |

---

## 一句話記住

> **struct 是印好欄位的卡片，enum 是「好幾種形狀選一種」的寶箱，而且每一種都得處理（`match` 窮盡）；可能沒有的東西就裝進扭蛋（`Option`），打開前先想好空的時候怎麼辦——Rust 裡沒有 null。**
