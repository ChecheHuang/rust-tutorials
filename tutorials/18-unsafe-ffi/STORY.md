# 故事版：遊樂園的員工專用門 🎡

> 這篇是**寫給小朋友也看得懂**的故事版。用一個「在遊樂園裡，只有簽了名的員工可以走員工專用門」的故事，幫你「感覺」出 `unsafe` 的真正意思、raw pointer、`split_at_mut` 這種 safe wrapper、`unsafe fn` 與 `# Safety`、FFI（`extern "C"`、`CString`、`CStr`、`#[no_mangle]`、`#[repr(C)]`）、Miri。故事裡不講程式名詞，名詞都放在 `>` 小框框和最後的對照表裡。先享受故事，別急著背。

---

## 員工專用門不是「沒有規矩」

小葵暑假在遊樂園幫忙。遊樂園到處都有**自動閘門**：身高不夠的不能玩、一個座位只能坐一個人，閘門會自己擋下來。

遊樂園後面有一扇「**員工專用門**」。園長說：「走這扇門，不代表園區規則都不算數了。排隊、繫安全帶，**一樣要遵守**。這扇門只讓你做**五件**閘門沒辦法幫你檢查的事。走進去之前，你要**簽名**：『這幾件事出了問題，我負責。』」

> 這就是 **`unsafe`**：它不是「關掉檢查」，借用檢查和型別系統**仍然有效**。`unsafe { ... }` 只解鎖五件事：deref raw pointer、呼叫 `unsafe fn`（含 FFI）、存取可變 `static`、實作 `unsafe trait`、存取 `union` 欄位。簽名的意思是：「編譯器證明不了的前提，由我保證。」

---

## 寫在紙條上的座位號碼

平常小葵帶遊客去座位，用的是園區的**電子手環**：手環會確認座位真的存在，也不會讓兩個人同時改同一個座位。

員工們還有另一種東西：**手寫紙條**，上面寫「C 區 5 號」。寫紙條**誰都可以寫**，沒什麼危險。可是**照著紙條走過去坐下**，就要走員工專用門——因為紙條可能是空白的、座位可能早就拆掉了，沒有人幫你檢查。

> 這就是 **raw pointer**：`let r_const: *const i32 = &x;`、`let r_mut: *mut i32 = &mut x;`。**建立**不需要 `unsafe`；**deref**（`*r_const`、`*r_mut = 10`）才要放進 `unsafe` 區塊。跟 `&T` 不同，raw pointer 可以是 null、不受借用規則保護、允許別名。

---

## 把一排座位切成兩半

一排雲霄飛車有 5 個座位。兩位工作人員要**同時**整理：一位整理前 2 個、一位整理後 3 個。

閘門不放行：「一排座位只能讓一個人整理！」它看不出來兩人整理的範圍**根本沒重疊**。

於是園長自己走員工專用門，親手把這排**從中間切開**，交給兩人各一半。兩人拿到的是普通手環，完全不用碰員工專用門。

> 這就是 **safe wrapper**：`v.split_at_mut(2)` 回傳 `(left, right)` 兩個可變 slice。編譯器無法證明兩段不重疊，所以標準函式庫**內部用 unsafe**，對外卻是 **safe API**。`Vec::push` 內部也是這樣。

## 危險遊戲門口的說明牌

園區裡有一個「**危險遊戲**」。要玩它，**一定要走員工專用門**才進得去。

門口掛了一塊說明牌：「玩之前請確定：身高超過 140 公分、沒有心臟病。」說明牌寫清楚**誰要保證什麼**，進去的人就知道自己簽的是什麼。

> 這就是 **`unsafe fn`** 和 **`/// # Safety`**：`unsafe fn dangerous()` 只能在 `unsafe { dangerous(); }` 裡呼叫。寫 `unsafe fn` 時要用 `# Safety` 段落寫明 caller 必須保證的條件（例如 pointer 有效、對齊、沒被別處改）。

## 外國旅行團的導遊

今天來了一團**外國旅行團**，他們說另一種語言，也有自己的規矩。小葵請他們的導遊幫忙：「請幫我量這句話有幾個字。」「請告訴我 -42 的大小是多少。」

園區沒辦法檢查外國導遊說的是不是真的，所以**每次找他們，都要走員工專用門**。

還有一個習慣不一樣：外國導遊讀句子，是讀到**句點**才停。小葵的句子本來沒有句點，所以她要先把句子**抄到一張有句點結尾的卡片上**，再交過去。卡片中間不能有句點，不然導遊會讀到一半就停。

> 這就是 **FFI 呼叫 C**：`extern "C" { fn strlen(s: *const c_char) -> usize; fn abs(x: i32) -> i32; }`，呼叫一律要 `unsafe`。Rust 字串不以 NUL 結尾，所以用 `CString::new("hello world")` 加上結尾 `\0`，再傳 `cs.as_ptr()`。字串中間有 null byte 時 `CString::new` 會回錯誤。

---

## 把外國卡片讀回來

外國導遊遞回一張只寫著「**在 C 區某處**」的紙條。小葵走員工專用門，照著紙條一路讀到句點，得到一句話。

但這句話也可能是**看不懂的文字**，所以她再確認一次：「這是我們看得懂的字嗎？」確認過才拿去用。

> 這就是 **`CStr::from_ptr`**：`let back: &CStr = unsafe { CStr::from_ptr(raw) };` 從 `*const c_char` 讀到 NUL 為止；`back.to_str()` 再檢查是不是合法 UTF-8，不是就回 `Err`。`CString` 是自己擁有的，`CStr` 是借來看的。

---

## 掛上外國名牌的園區導覽員

反過來，外國旅行團也想找**我們的導覽員**幫忙算數。

園區平常會在員工名字後面加一長串內部編號，外國導遊根本找不到人。所以這位導覽員掛上一塊**不加編號的名牌**，只寫「rust_add」，而且**照外國的規矩說話**。

如果要交給外國人一張「座位表」，欄位的順序也要**照外國的排法**，不能讓園區自己為了省空間亂調。

> 這就是 **讓 C 呼叫 Rust**：`#[no_mangle] pub extern "C" fn rust_add(a: i32, b: i32) -> i32`。`#[no_mangle]` 關掉 name mangling，讓 linker 找得到符號；`extern "C"` 用 C 的呼叫慣例。struct 要加 `#[repr(C)]` 才會用 C 的欄位排法。要輸出給 C 用就設 `crate-type = ["cdylib", "staticlib"]`；`cbindgen` 能自動產 C header，`bindgen` 則反過來從 C header 產 Rust 宣告。

## 先檢查，再走捷徑的櫃台

園區有一個寄物櫃台，有 3 個格子。平常每次拿東西，系統都會再檢查一次「這格存在嗎」。

櫃台阿姨的做法是：**她自己先檢查**「你要的格子號碼小於 3 嗎？」不是的話直接拒絕。確定沒問題後，她才走員工專用門，**跳過系統的第二次檢查**，直接拿。

遊客只看到一個普通的櫃台，從來不需要簽名。

> 這就是 **`SafeIndex::get`**：先 `assert!(i < self.data.len(), "out of bounds")` 確認前提，再 `unsafe { *self.data.get_unchecked(i) }`。公開 API 是 safe 的，unsafe 的前提條件在裡面就驗證完了。

## 夜間巡邏員

晚上園區關門後，有一位**夜間巡邏員**把所有員工專用門走過一遍，看看有沒有人照著**作廢的紙條**坐到拆掉的座位、有沒有紙條**指歪了位置**。

園長還交代：「如果園區裡出事要大喊，**不要喊到外國旅行團那邊去**，他們不懂我們的喊法，會一團亂。」

> 這就是 **Miri** 與 **FFI 邊界的 panic**：`cargo +nightly miri test` 能抓 dangling pointer、未初始化讀取、對齊錯誤等 UB。Rust 的 panic unwind 穿過 C 邊界是 UB，要用 `catch_unwind` 擋住。

## 回到現實：故事 ↔ Rust 對照表

| 故事裡的東西 | 真正的 Rust 概念 |
|------|------|
| 自動閘門 | 借用檢查、型別系統 |
| 員工專用門＋簽名 | **`unsafe { ... }`**（我負責前提） |
| 只解鎖五件事 | unsafe 的 5 個超能力 |
| 手寫座位紙條 | **raw pointer** `*const T` / `*mut T` |
| 寫紙條不用走門、照紙條走才要 | 建立 safe、**deref 才要 unsafe** |
| 園長把一排座位切兩半 | `split_at_mut`（safe wrapper） |
| 危險遊戲 | **`unsafe fn`** |
| 門口說明牌 | `/// # Safety` 文件 |
| 外國導遊 | **`extern "C"`** 宣告的 C 函式（`strlen`、`abs`） |
| 有句點結尾的卡片 | **`CString`**（NUL 結尾） |
| 讀到句點、再確認看得懂 | `CStr::from_ptr` + `to_str()` |
| 不加編號的名牌 | **`#[no_mangle]`** |
| 照外國規矩說話 | `pub extern "C" fn rust_add` |
| 照外國排法的座位表 | **`#[repr(C)]`** |
| 先檢查再走捷徑的櫃台 | `SafeIndex::get`：`assert!` + `get_unchecked` |
| 夜間巡邏員 | **Miri** |
| 別把大喊傳到外國團 | panic 不能跨 FFI 邊界 |

## 一句話記住

> **`unsafe` 是員工專用門，不是拆掉規則：寫紙條（raw pointer）誰都能寫，照著走才要簽名；找外國導遊（`extern "C"`）要帶句點結尾的卡片（`CString`）；最好的做法是自己先檢查好，再給大家一個不用簽名的普通櫃台（safe wrapper）。**
